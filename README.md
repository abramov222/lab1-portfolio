# Лабораторная работа 1 — Страница-визитка

## Описание проекта
Статичная одностраничная страница-визитка, разработанная в рамках лабораторной работы. Проект демонстрирует базовые навыки HTML5 и CSS3, включая работу с семантическими тегами, якорными ссылками, Flexbox, CSS Grid и адаптивной вёрсткой.

## Технологии
- HTML5 (Семантическая разметка)
- CSS3 (Flexbox, Grid)
- Адаптивный дизайн (Mobile-first / Desktop-first, 3 breakpoints)
- Git, GitHub

## Структура секций
1. `Header` (Шапка с навигацией)
2. `About` (Обо мне)
3. `Skills` (Навыки)
4. `Portfolio` (Примеры работ)
5. `Contacts` (Контактная информация)
6. `Footer` (Подвал)

## Запуск проекта
Проект не требует сборки. Достаточно склонировать репозиторий и открыть файл `index.html` в любом современном браузере.
